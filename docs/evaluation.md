## 不能由本轮推出的结论

- 每格一次、同一个小型合成项目，不是重复统计实验。
- B/E 同时改变上游版本和规则，无法把差别归因于单条补丁。
- 没有原始 Cursor 对照，也没有测全部技能。
- 隔离环境屏蔽了 Herdr/gh，没测真实 MCP、浏览器、远端发布或持久工作者。
- 外部 codex-exec 的模型设置、打印模式的异步续接和人工追问都是混杂因素。

因此推荐理由是：保留已经证明有用的轻量规则、降低维护差异，并以本地安装和具体能力 smoke 逐步验收；不是承诺与上游全平台等价。以后的评测原始证据应放在持久、已脱敏的记录目录，不再只留 `/tmp`。

## 本次收尾的真实 smoke（2026-10-02）

在独立临时目录执行 `npm pack`，解包后分别用 earendil 0.87.0 和原版 Pi 0.73.1 的 CLI 执行 `install <解包目录>`、`list`，两套的退出码均为 0，来源路径指向独立包副本，不依赖开发仓库文件。

在新的隔离配置目录、无其他扩展、禁用全部工具的条件下，各做一次有 90 秒上限的真实调用，没有重试、子代理或 OAuth 刷新：

```text
pi -p --mode json --no-tools --no-context-files --no-prompt-templates --no-themes \
  --session-dir <本次记录目录> --model <provider/model> --thinking low \
  '/skill:pstack-bro 请把“该变更改善了数据持久化语义”改写成一句普通中文。不要调用工具，也不要提内部流程。'
```

| 模型 | 结果 | 模型实际回复 |
|---|---|---|
| cpa/deepseek-v4.1-flash | 成功，约 2.0 秒 | 这次改动让数据的保存和读取规则更清楚了。 |
| openai-codex/gpt-5.6-sol | 成功，约 7.1 秒 | 这个改动让数据保存更可靠。 |
